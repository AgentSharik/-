# ТРЕТЬ ЖИЗНИ v6 — производственные заметки (статус на 2026-09-21)

## Хронометраж
Точный расчёт: **7:33** (453.8 c, 13 615 кадров @30 fps) — см. `docs/TIMING_v6.md`,
машина таймлайна: `tools/timing_v6.py` → `audio/v6/timeline_v6.json`.
Суммы актов из сценария (350 c = 5:50) не учитывали реальный темп VO и hold-кадры;
по VO-модели (1.55 слов/с + паузы + lead/tail 0.9/1.1 c) фильм попадает в коридор 7:20–7:50.
Опция ужимки до ~7:24: lead/tail 0.6/0.8 c.

## Замечания (1)–(4): статус
1. **Всё покадрово, больше PNG-кадров** — сделано: рендерер `tools/animate_v6.py`
   строит УНИКАЛЬНЫЙ PNG на каждый кадр 30 fps: посимвольное заполнение текста
   (своё состояние текста на кадр), субпиксельный zoom/pan по ease-кривой,
   мерцание света, пылинки, зерно, виньетка, чернильная вспышка в точке письма.
   Демо-проход: SH-01 (390 кадров), SH-02 (392), SH-24 (360) → `assets/preview/*_preview.mp4`,
   ключи каждых 2 c → `assets/frames_keys/`. Звук событий (ступ/перо/каретка/звонок)
   собирается из ТОГО ЖЕ расписания символов → синхрон идеален: `audio/v6/sfx/*_sfx.wav`.
2. **Текст заполняется покадрово и красиво** — сделано для SH-01/SH-02/SH-24:
   чернильный serif с дрожанием глифов, перспективная укладка по странице дневника,
   печать посимвольно под шорох пера; терминальные карточки — моноширинный зелёный
   с кареткой, scanlines и свечением.
3. **Планшет «задом наперёд»** — исправлено: `art/v6/SH06_cot_clipboard.png`
   (клипса сверху, бумага к глазам врача, вторая рука пишет).
4. **Выбивалось из стилистики + мультяшность + лаборатория не подземная** —
   перегенерированы: SH-02 (дневник, пустая страница под посимвольную печать),
   SH-03 (подземный бункер: бетон, трубы, венткороба, без окон),
   SH-06 (подземная лаборатория), SH-07 (воксельный CRT, плоская линия, отражение Ветрова).
   Стиль-якорь: «кинематографичный воксельный Minecraft, реалистичный свет,
   объёмная дымка, плёночное зерно, НЕ мультяшно, НЕ painterly».

## Репродьюс / мастер-рендер
Демо-проход был 960×540 из-за лимита tmpfs песочницы. Мастер 1080p:
`python3 tools/timing_v6.py && python3 tools/animate_v6.py 1920 1080`
(конвейер сам кодирует mp4 и чистит PNG-плиты; ключи и sfx складываются в репо).
